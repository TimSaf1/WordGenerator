# Генератор слов, выражений и словосочетаний

Простой статический веб-сайт (HTML + CSS + JS, без сборки и зависимостей).

## Как запустить
Открыть `site/index.html` в браузере, либо запустить локальный сервер:
```bash
cd site
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Возможности
- **8 сфер жизни** (чекбоксы): ИТ, повседневная жизнь, наука, бизнес, медицина, культура, спорт, путешествия + кнопки «Выбрать все» / «Снять все».
- **Тип лексики**: только слова / выражения / словосочетания / все типы.
- **Количество карточек**: слайдер от 1 до 10.
- Каждая карточка содержит:
  - термин и краткое описание;
  - похожие и связанные слова (клик по «чипу» копирует слово в буфер обмена);
  - ссылку на информационный ресурс (Википедия);
  - ссылку на статью/хаб по теме;
  - иллюстрацию (picsum.photos).
- Дополнительные фичи: режим «без повторов между генерациями», отключение картинок, понятные уведомления при пустом результате, адаптивная сетка карточек.

## Файлы
- `site/index.html` — разметка страницы;
- `site/style.css` — стили (белый фон, чёрный текст);
- `site/data.js` — база из 49 слов/выражений/словосочетаний по 8 сферам;
- `site/app.js` — логика фильтрации, генерации и рендера.

Чтобы добавить новые слова — просто допишите объект в массив `WORDS_DB` в `site/data.js`.
